# 🚀 Personal Portfolio Website

Hi! I'm **David Idowu**, a 2nd-year Computer Science student and aspiring Full-Stack Software Developer. This is my professional portfolio website built to showcase my projects, technical skills, and journey in software engineering.

## 🔗 Live Demo
Check out the live site here: [https://blaze10111.github.io/my-Personal-portfolio/](https://blaze10111.github.io/my-Personal-portfolio/)

## ✨ Key Features
- **Fully Responsive Design:** Optimized for mobile, tablet, and desktop viewing using CSS Flexbox and Media Queries.
- **Interactive UI:** Dynamic tabbed sections for Skills and Education powered by JavaScript.
- **Custom Side Navigation:** A mobile-friendly sliding navigation menu.
- **Functional Contact Form:** Integrated with **Google Apps Script** to send form submissions directly to a Google Sheet in real-time.
- **Smooth Navigation:** Implemented smooth-scrolling for a better user experience.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Icons:** [FontAwesome](https://fontawesome.com/)
- **Fonts:** [Google Fonts (Poppins)](https://fonts.google.com/)
- **Backend/Data:** Google Apps Script & Google Sheets API
